# Google Drive Integration

## Purpose

This file documents the Google Drive folder structure and configuration used in the project.

## Links

- [Google Cloud Console - Create Client](https://console.cloud.google.com/auth/clients/create?project=gen-lang-client-0369583419)

## Why is it used?

The Google Cloud Console link is used to create and manage OAuth 2.0 Client IDs for the project `gen-lang-client-0369583419`. This is necessary for enabling the application to upload artifacts directly to Google Drive via the Drive API.
